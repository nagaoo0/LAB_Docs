title: "User Interface"
---

On-screen UI for your game. The HUD is the foundation, the UI Designer is where you lay it
out, and widgets are the interactive controls built on top.

1. [HUD (On-screen UI)](01-hud.md) — UI Transform, sprites, text, hit testing
2. [UI Designer](02-ui-designer.md) — the canvas panel for laying out the HUD
3. [UI Widgets](03-ui-widgets.md) — buttons, toggles, sliders, text fields, layout containers

To drive UI from code, see the Lua [HUD](../06-scripting/02-lua/api/entity/10-hud.md) and
[HUD interaction](../06-scripting/02-lua/api/ui/01-hud-interaction.md) reference pages.
